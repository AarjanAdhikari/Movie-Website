## Core Features

### Movie Discovery

Browse trending, popular, top-rated, and upcoming movies with continuously updated data from TMDB.

### Intelligent Search

Search movies in real time with instant results and seamless navigation.

### Movie Details

View comprehensive information including ratings, release dates, genres, runtime, cast, synopsis, and trailers.

### Personalized Watchlist

Save favorite movies locally for quick access across browsing sessions.

### Responsive Experience

Optimized layouts for desktop, tablet, and mobile devices.

### Dynamic Interface

Modern, lightweight interface with smooth navigation and fast page interactions.

---

## Data Source

Movie data is provided by **The Movie Database (TMDB)** through its public API. All movie metadata, posters, ratings, and related information are retrieved in real time.

## Performance

The application is designed to deliver a responsive browsing experience through efficient API requests, lightweight assets, and client-side rendering techniques.

## Getting Started

Clone the repository.

```bash
git clone https://github.com/AarjanAdhikari/Movie-Website.git
```

Navigate to the project directory.

```bash
cd <repo-name>
```

If the project uses a local development server, start it using your preferred tool (for example, VS Code Live Server). If it is built with a package manager, install dependencies first:

```bash
npm install
npm run dev
```
